# YatraSetu — Project Description

## 1-Paragraph Project Submission Description

**YatraSetu** is an autonomous, Solana-powered tourism intelligence and price protection platform engineered to safeguard travelers across India from unfair tout markups, fake guides, and surge pricing. Built with Next.js 14 and Anchor smart contracts, YatraSetu pairs personalized cultural itineraries tailored to travel pace and squad size with real-time municipal fair-fare auditing, Metaplex-verified on-chain AI concierge identities, tamper-evident SHA-256 itinerary agreements anchored to Solana Devnet, verified traveler reviews, and self-contained emergency offline travel passes to deliver complete peace of mind for both domestic and international explorers.
