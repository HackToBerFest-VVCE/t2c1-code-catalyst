# Touristमत्रम् AI

## About:
Touristमत्रम् AI is an AI-powered tourist assistance application that helps travellers find tourist attractions, public facilities, transportation, and fair price information. It also suggests places based on users' interests and budget to make travel easier and more affordable.

## Objectives:
- To simplify trip planning using AI.
- To help tourists find reliable travel information.
- To save tourists time and money.

 ## Current Status:
The project is in the initial planning stage. Development is about to begin.

 ## Planned Features:

- Fair price information.
